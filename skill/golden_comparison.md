# 用冻结参考复核加速器

适用于输出可逐条比对的定点加速器；参考由独立实现产生。

1. 先记录接口契约：元素数、记录顺序、位宽、字节序、有效位、保留位、定点比例及舍入。保留输入、参考、参数和版本校验。
2. 使用正常、空场、阈值边缘、饱和、短目标及多次连续帧；编译实际 RTL 运行，或从真实板卡采集输出，分开标识。
3. 先查长度和保留位，再逐条比对有效位。坐标误差只统计两侧共同有效的记录，但任何有效位差异均判失败。
4. 独立执行反例：错误长度、无效记录非零、越界坐标、有效位不匹配及容差边界。命令：`python 01_fpga_baseline/tools/test_comparator.py`。
5. 复跑真实板测归档：`python tools/compare_board_capture.py`。用例中的 0.25 像素阈值是条纹接口测试的限值，不能外推物体几何精度。

边界：参考自身错、输入和参考错配、含非逐条对应输出、优化改变定义时，须改参考和验证策略。禁止从同一 DUT 的输出直接生成“黄金参考”。
