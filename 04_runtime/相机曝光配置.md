# 正式相机曝光配置

2026-10-20当前场景的固定曝光20会导致大量饱和列，三帧只有11个共同合格列；一次固定曝光5的真实采图得到129个共同合格列，且PS/PL一致。原始记录保存在13_system_test_20261020。本次把曝光5接入正式构造参数；这些历史数据不是修改后新做的一次硬件测试。

`PLStripeCheckedCamera(source, roi, driver, exposure=5, timeout_s=40)`默认使用5，也可显式传入20。`PerPoseExposureCamera`和旧PS的`StripeCheckedExposureCamera`保留默认20兼容历史调用，但都可传入`exposure=5`。曝光是相机V4L2控件的整数原始值，不是任意推定的毫秒数。

构造阶段检查曝光为正整数、能表示为V4L2有符号32位数；工作进程打开相机后，仍先查询实际硬件支持的范围和步长，再设置手动AE与曝光，逐帧核对读回值。父进程同时检查报告中的请求值、三张激光原图的AE/曝光读回、九张原图指纹，以及恢复和释放结果。传入另一相机不支持的曝光会停止本次采集，不自动换曝光重试。

每次采集仍保存三张激光原图及前后各三张定位图，恢复原AE/曝光并释放相机；不改白平衡与增益。质量审查仍使用原门限，并要求至少20个共同合格列。曝光5不会降低饱和、白邻域、多峰或三帧稳定性检查。

电脑验证命令：

```text
python 09_tools/check_camera_exposure.py
```

测试包括正式API传参、原图/读回记录不一致时停止，以及13目录真实曝光5图像和实际PL输出的离线重放。测试用归档输出替代当前硬件，不能当作新增板测或同一overlay的电机联合验收。
